
# Python Data Processing

## Internship
Veda Technology - AI & ML Internship

## Task
Day 9 - Python Data Processing

## Objective
To process structured student records and generate useful summary statistics using Python.

## Tools Used
- Python
- Pandas
- Google Colab / Jupyter Notebook

## Features
- Processes student records using a function
- Calculates average, highest and lowest marks
- Identifies pass and fail counts
- Assigns grades to students
- Generates department-wise average marks
- Displays examples of processed records

## Dataset
The project uses sample student records containing names, departments and marks.

## Result
The program successfully processes the records and generates summary statistics and processed student data.

## Files
- Python_Data_Processing.ipynb - Python program and results
- README.md - Project documentation
- requirements.txt - Required Python library

## How to Run
1. Open the notebook in Google Colab or Jupyter Notebook.
2. Install pandas if required using `pip install pandas`.
3. Run all cells to view the processed records and summary statistics.
